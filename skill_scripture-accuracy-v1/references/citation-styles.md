# Citation styles

## Contents
- Default style

## Default style

`John 3:16 (NIV)`

Give the translation abbreviation the first time a verse appears in a piece. If the whole piece uses one translation, say so once ("All Scripture is from the NIV unless noted") and drop the abbreviation after the first citation, but keep it on any verse from a different translation.

## Alternatives

| Use | Style | Example |
|---|---|---|
| Popular / web | Name, reference, translation in parentheses | Romans 1:16 (NIV) |
| Popular, comma form | Reference, translation after comma | Romans 1:16, NIV |
| Academic (SBL-style) | Short book abbreviation, no period, translation after | Rom 1:16 NIV |
| Footnote or endnote | Full reference with translation | Romans 1:16 (NIV). |

Pick one and use it everywhere in the piece. If the user's venue has its own style guide, follow that.

## Formatting rules

- Book names: spell out in running text (1 Corinthians, not 1 Cor. or I Cor.). Use a numeral for numbered books.
- Chapter and verse: colon between them (3:16).
- Verse ranges: en dash (5:22–23). Chapter ranges: en dash with chapter:verse on both ends (Galatians 5:22–6:2).
- Non-adjacent verses: comma (John 3:16, 18).
- Reference placement: after the quote, or before it when introducing it. Not both.
- Block quotes: quotation marks or blockquote formatting, reference below or beside it.
- Ellipses: use only when words are removed from inside a quoted verse, and make sure removal does not change the meaning.
