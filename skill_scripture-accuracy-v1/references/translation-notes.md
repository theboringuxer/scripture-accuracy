# Translation notes

Quick guidance for choosing or recommending a translation. Positions on the spectrum are general and sources differ slightly, so treat them as a guide, not a ranking.

## Contents
- The spectrum
- Choosing for the audience
- Rules for any translation
- Paraphrases
- When to suggest a change

## The spectrum

| Approach | Goal | Examples |
|---|---|---|
| More formal (word-for-word) | Stay close to the original wording and structure | NASB, ESV, KJV, NKJV |
| Balanced | Keep the wording close while reading naturally | CSB, NIV, NRSV, NET |
| More dynamic (thought-for-thought) | Prioritize natural, readable English | NLT, NIrV |
| Paraphrase | Restate the meaning freely | The Message (MSG) |
| Expanded | Adds explanatory words in brackets | Amplified (AMP) |

## Choosing for the audience

- **Study notes, academic or doctrinal pieces:** a more formal translation, so a reader can see the wording the argument depends on.
- **General articles, talks, web copy:** a balanced translation. It reads naturally and is widely recognized.
- **Younger readers, new readers, or a broad audience:** a more dynamic translation, or a balanced one with short quotes.
- **Devotional or reflective pieces:** whichever translation the audience already uses. Familiar wording lands better than a perfect one.
- **When the argument turns on a single word:** use a more formal translation and consider an original-language note.

If the user's church, publisher, or audience uses one translation, default to it.

## Rules for any translation

- Use one translation per piece. Switching is fine only when it is signaled and has a reason (for example, comparing how two translations render one word).
- Do not mix wording from two translations inside one quotation.
- Verify wording against the translation's actual text, not memory. Translations differ by a single word in ways that are easy to miss.
- Verses often differ between editions of the same translation (for example, the 1984 and 2011 NIV). Check which edition the user means.

## Paraphrases

The Message and similar editions are restatements. They are fine for devotional reading but should not be presented as "what the text says" in an argument. If a paraphrase is used, label it as a paraphrase, and check the same passage in a standard translation to make sure the meaning holds.

## When to suggest a change

Say it briefly and only when it helps: a formal translation for a word-level argument, a more readable one for a general audience, a single translation where the piece mixes several. Never push a translation on theological grounds. Offer the practical reason and let the user decide.
